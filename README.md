# Hotel--Booking--Performance---Dashboard
## Project Overview
This project analyzes hotel booking data using Power BI to provide insights into booking trends, cancellations, hotel performance, customer segements, and revenue related metrics.
## Tools used
-Power BI
-Power Query
-DAX
-Excel
## Dashboard Features
-KPI Cards
-Monthly Booking Trend
-Booking by Hotel Type
-Booking by Market Segment
-Cancellations by Hotel Type
-Interactive Slicers
-Drill Down

## KPIs
-Total Bookings
-Total Cancellations
-Cancellation Rate
-Average ADR
-Total Guests
-Average Length of Stay

## Key Insights
-City hotel received more bookings than Resort Hotel.
-Online TA generated the highest bookings.
-Cancellation Rate was 27.63%
-Average ADR was $106.75.
-Average Length of Stay was 3.63 days.
